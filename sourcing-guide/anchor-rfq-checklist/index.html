What Information Should a Buyer Provide for a Concrete Anchor RFQ?

Anchor quotations can be misleading when the RFQ contains only a diameter and length. Base material, embedment, fixture details and project requirements matter, especially where structural performance is involved.

Anchor RFQ Checklist

Provide the project-controlled information that applies to the selected anchor system.

  • Anchor type
  • Base material and relevant project condition
  • Diameter and overall length
  • Thread size
  • Effective embedment depth
  • Fixture thickness
  • Hole diameter and depth where specified
  • Edge distance and anchor spacing where project-controlled
  • Required load direction / project design reference
  • Material and finish
  • Applicable standard, evaluation report or project approval requirement
  • Quantity by SKU
  • Packing, marking and documentation requirements

Why Base Material Must Be Confirmed

Concrete, brick, block and other masonry materials are not interchangeable base materials.

The selected anchor design and installation requirements must match the actual base material and project specification. CHS does not infer structural suitability from product appearance.

What CHS Will Not Assume

Safety-critical claims must stay tied to reliable evidence.

  • Load capacity from diameter alone
  • Approval or certification without the exact supporting report
  • Suitability for cracked / uncracked concrete without project or product evidence
  • Corrosion suitability without the specified material / coating and exposure requirement
  • Interchangeability between mechanical and bonded anchors
